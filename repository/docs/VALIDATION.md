# Validation scope

The player release contains the exact nine runtime files listed in spec/accepted_runtime.json. Manual acceptance covered purchase, all upgrades, summon restrictions, ordinary-enemy/Boss aggro, stock persistence/native NG replenishment, and inventory/detail/hotbar/original-icon display. The ordinary desktop ModEngine2 configuration was also accepted.

Read-only live evidence recorded +10 maximum HP 14250 (base 1920 times 7.422, truncated) and poison/rot/bleed/frost thresholds 133. Effect 440 and the ordinary-spirit target-priority/perception adaptation were retained.

Every spell/healing trigger, final per-element damage/negation/status accumulation, spirit death and every story state were not separately isolated. The second ordinary-region name and distinct high/low UI quality settings were not individually reported.

Source reconstruction and compilation checks do not replace manual gameplay acceptance of newly changed binaries or unsupported executable profiles. No private save, runtime memory reader or gameplay-debugging tool is included in this source snapshot.
