# Credits and permissions

## Original game content

ELDEN RING and its original characters, models, animations, sounds and other game assets belong to their respective rights holders. The mod reuses Melina's installed game resources. Original image collections, character models, animations and audio are not included in this archive. Modified regulation/message/layout files are provided as mod resources for the supported game installation.

## AI disclosure

The custom in-game icon was AI-generated and selected after user-directed revisions. Mod configuration, icon-helper code and release documentation were also developed with generative AI. The mod was manually tested by its commissioning player. This disclosure applies to both the main download and optional icon-helper sources.

## Third-party components

- MinHook 1.3.4: hook library used by MelinaIcons.dll. Its license is in LICENSES/MinHook.txt. https://github.com/TsudaKageyu/minhook
- ERNativeUI: native-image interface and ownership research used for the small-icon implementation. Its MIT notice is in LICENSES/ERNativeUI.txt. The ERNativeUI host DLL is not included or required. https://github.com/Flammrock/ERNativeUI
- MinGW-w64 runtime notices for the Windows binary are in LICENSES/MinGW-w64-COPYING.txt.
- ModEngine2 is a separately installed requirement, not bundled. https://github.com/soulsmods/ModEngine2/releases
- WitchyBND, DirectXTex and Zig were used during asset processing/building; these tools are not bundled.
