# Melina Spirit Ash — 1.1.0

## GitHub distribution edition, revision 1

- Repackaged the accepted 1.1.0 build for GitHub Releases.
- Runtime files are byte-identical to the accepted build. No gameplay, text, or image changes were made for this distribution edition.
- Main archive includes runtime files, bilingual instructions, relative-path configuration guidance, checksums, and third-party notices.
- Public parameter/text builders, numeric configuration, icon sources and custom UI assets are in the separate repository snapshot. Sources are not required to play.

## 1.1.0

- Replaced full original-image archive overrides with two independent custom Melina image payloads.
- Added MelinaIcons.dll to register the small icon and route the detail image. Other icons use the player's original game resources.
- Retained 1.0 gameplay parameters and Simplified Chinese text.

## 1.0

- Standalone Melina spirit ash, sold by Twin Maiden Husks for 10,000 runes, one per journey.
- 132 FP summon cost and ordinary spirit-ash restrictions.
- Ghost Glovewort upgrades through +10 with custom stat progression.
- Original Morgott-battle Melina appearance, moves, combat AI and incantations retained; perception and target-selection settings adapted for ordinary spirit-ash use.
- Simplified Chinese item and summon-bar names, descriptions, and a custom icon.

## Verification scope

Manual acceptance covered purchase, upgrades, summon restrictions, ordinary-enemy/Boss aggro, stock persistence/NG replenishment, and inventory/detail/hotbar/original-icon display. Live +10 HP and resistance thresholds were also read and checked.

Every individual spell/healing trigger, final per-element damage/negation/status-buildup case, spirit death, and story state was not separately isolated. This release does not claim exhaustive coverage of those cases.
